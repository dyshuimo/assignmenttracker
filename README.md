# Assignment Tracker Program

## Description
Assignment Tracker is a python command line program that tracks assignment, user can record assignment's name, subject, add description and due date, and completion status.
User can view all the assignments, filter by subject, and delete / mark assignment as completed.
## How to Run
The main program is main.py
```python
python main.py
```
After that, it will prompt user to choose a option from the menu
